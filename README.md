# Accident Epics

Accident Epics is a simple project designed to help users track, manage, and analyze accident reports or incidents. The goal is to make it easy for individuals, small organizations, or teams to record accidents, view summaries, and gain insights into safety trends without complicated software.

## Who is it for?

- **Local Police Stations** needing an easy way to record and review accidents. or safety incidents.
- 
## Features

- Record accident reports with essential details.
- View and filter historical accident data.
- Simple dashboard for summaries and trends.

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (recommended v18+)
- [npm](https://www.npmjs.com/) or [yarn](https://yarnpkg.com/)

### Installation

1. Clone this repository:
   ```sh
   git clone https://github.com/pr8teen/accident-epics.git
   cd accident-epics
   ```
2. Install dependencies:
   ```sh
   npm install
   ```
   or
   ```sh
   yarn
   ```

### Running the Project

Start the development server:
```sh
npm start
```
or
```sh
yarn start
```

The app will be available at [http://localhost:3000](http://localhost:3000) (or a port specified in your config).

## Usage

- Add new accident reports via the interface.
- View and filter existing reports.
- Explore basic statistics on the dashboard.
